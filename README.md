# On Duty English — Practice Sheets

Free practice sheets for every lesson on [@ondutyenglish](https://www.youtube.com/@ondutyenglish).

**Practice sheet index:** https://oabuilds.io/

## URL Structure

Each lesson's practice sheet is accessible at a clean, predictable URL:

```
https://oabuilds.io/practice/L008/L008_practice_sheet.pdf
```

Shortened alias (once custom domain is configured):
```
https://ondutyenglish.com/practice/L008
```

## Adding a New Lesson

1. Create directory: `practice/LXXX/`
2. Copy PDF: `practice/LXXX/LXXX_practice_sheet.pdf`
3. Add redirect: `practice/LXXX/index.html`
4. Add card to `index.html`
5. Commit and push — GitHub Pages deploys in ~60 seconds
